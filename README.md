# Landing Page Previews

A public gallery of tailored landing-page concepts for prospective clients.

## Structure

- `docs/index.html` — preview gallery
- `docs/mao-vet/` — Mao Veterinary Clinic concept
- `docs/salam-pets/` — Salam Pets Clinics concept
- `docs/cat-houses/` — Cat Houses clinic, branches and mobile-service concept
- `docs/mazaya-vet/` — Mazaya Pet Clinic late-hours, services and offers concept
- `docs/ramz-aleef/` — Ramz Aleef / Pet Code Clinic services, social and location concept
- `docs/aman-delta/` — Aman Delta multi-branch veterinary clinic concept
- `docs/life-touch/` — Life Touch care and pet-boarding concept
- `docs/pet-valley/` — Pet Valley care, grooming and boarding concept

The site is published with GitHub Pages from the `docs` directory.

## Important

Each concept is an independent, unofficial proposal built from publicly available business information. Brand assets remain the property of their respective owners.
